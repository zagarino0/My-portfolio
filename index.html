Savoir-faire

Interface

React, React Native sous Expo, JavaScript et TypeScript, HTML et CSS. Intégration de maquettes, design responsive, états d'erreur et de chargement traités comme le reste.

Serveur

Node.js et Express, conception d'API REST versionnées, authentification par jeton, gestion des rôles et des permissions par middleware.

Données

PostgreSQL, modélisation relationnelle, Prisma. MongoDB quand le besoin le justifie. Le schéma se décide avant le premier écran.

Langues
